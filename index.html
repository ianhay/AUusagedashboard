What this can and cannot see

Reliable

Agent CLI tools write a token count to disk for every assistant turn. Claude Code stores one JSONL transcript per session under ~/.claude/projects/, and each assistant record carries input, output, cache-write and cache-read counts along with the model name and timestamp. This happens on API, Pro and Max plans alike. That is the data behind every chart here.

Approximate

Costs are calculated from the editable rate card on the Pricing tab, not from provider billing. Treat them as an estimate for comparison, not reconciliation. There are also known cases of the local JSONL counts diverging from what the provider bills, so the totals are best read as a trend rather than an invoice.

Not available

Browser chat sessions on Claude, ChatGPT and Gemini publish no token counts at all, so they have to be entered by hand. Anthropic's Usage and Cost Admin API needs an sk-ant-admin key and an organisation account — ordinary API keys have no access to usage endpoints, and a static page could not call it cross-origin regardless. Consumer plan quota percentages are not exposed anywhere, which is why the Budgets tab asks you to define your own caps.

Adding another provider

The parser sniffs each record for a usage object rather than matching a fixed schema, so it already understands Anthropic's input_tokens shape, OpenAI's prompt_tokens shape and Gemini's promptTokenCount shape wherever they are nested. Any new tool writing one of those three will import without a code change. Add a matching row on the Pricing tab to get costs.
