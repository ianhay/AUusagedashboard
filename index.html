Why long conversations are so expensive. A chat UI resends the entire thread every time you send a message, so turn 40 costs roughly forty times what turn 1 did. Input grows with the square of thread length while output grows linearly. That is what exhausts a plan limit — rarely many short chats, almost always one very long one.

What is measured and what is guessed

Exact

Conversation counts, message counts, roles, timestamps, thread lengths, which model was recorded, and character volume. These come straight out of the export and are as accurate as the file is.

Estimated

Everything token-shaped, and therefore every cost. No provider puts token counts in a chat export, so tokens are derived from characters at the ratio set on the Settings tab and then run through the context model. Two consequences worth holding on to: the ratio is a blunt average that varies with language and code density, and the estimate ignores prompt caching, which providers use internally to make repeated context cheaper than the raw arithmetic suggests. Read the numbers as an upper bound and a way to rank conversations against each other, not as a bill.

Missing

Attachments and images are only partly counted — Claude exports carry extracted text for attachments, which is included, but an image contributes tokens that no export records. Conversations deleted before an export was requested are absent from it permanently. Anything you did on a provider you never export is invisible.

Gemini specifically

Google Takeout supplies an activity log rather than threads: prompts are recorded, responses largely are not, and there is no conversation grouping. Prompts are therefore grouped by day into one pseudo-conversation, marked prompt-only, and their estimates are far rougher than the other two. Treat Gemini figures as an indication of activity, not of spend.

Why there is no live meter

Consumer plans publish no quota over any API, and a static page could not call one cross-origin regardless. Exports are point-in-time snapshots you request manually, so this dashboard is deliberately retrospective: it tells you what happened and what it likely cost, not what is left.
